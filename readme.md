# Pawn Patrol

Free chess tools at [pawnpatrol.eu](https://pawnpatrol.eu). It started as a Chess.com stats viewer for four friends who play every day and support each other in this journey, and now hosts a handful of tools:

- **Chess.com Stats** (`/stats/`): ratings, results, accuracy and time played for a group of players
- **Memo Rush** (`/memo/`): memorize a position, then rebuild it against the clock
- **FEN Player** (`/fen/`): play any position against Stockfish
- **Puzzle Mountain** (`/puzzles/`): climb the Lichess puzzle database 50 points at a time
- **Tournament Results** (`/tournaments/`): clean Chess-Results standings and player pages

See `CLAUDE.md` for how the site is put together and how tools are synced in.
